🤖 Rule-Based Chatbot – AI Internship Task 1

📌 Project Overview

This project is a simple Rule-Based Chatbot developed using Python. It interacts with users through predefined rules and provides automatic responses based on user input.

🎯 Objectives

- Understand basic chatbot development.
- Implement Python if-else statements.
- Learn basic pattern matching.
- Develop a simple conversation flow.
- Explore basic NLP concepts.

🛠️ Technologies Used

- Python
- Google Colab
- Conditional Statements
- While Loop
- String Matching

⚙️ How It Works

The chatbot accepts user messages and checks them against predefined conditions.

It responds to the following inputs:

User Input| Chatbot Response
Hello / Hi| Greeting message
How are you| Status response
Your name| Introduces itself
Help| Assistance message
Thank you| Welcome message
Bye| Ends the conversation

🚀 How to Run

1. Open the notebook in Google Colab.
2. Run the Python code cell.
3. Enter a message in the input field.
4. Receive an automatic response.
5. Type "bye" to exit.
